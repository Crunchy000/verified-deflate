# verified-deflate

A DEFLATE ([RFC 1951]) compressor and decompressor, with ZIP archive
reading and writing, in safe Rust with no dependencies. Its key properties
are proven with the [Kani] model checker. *(Full README in progress.)*

[RFC 1951]: https://www.rfc-editor.org/rfc/rfc1951
[Kani]: https://github.com/model-checking/kani
